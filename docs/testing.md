# Тестирование системы

| ID | Тест | Ожидаемый результат |
|----|------|---------------------|
| TC-01 | Добавление сотрудника | Сотрудник появляется в списке |
| TC-02 | Редактирование сотрудника | Данные обновляются |
| TC-03 | Удаление сотрудника | Запись удаляется |
| TC-04 | Поиск сотрудника | Найден нужный сотрудник |
| TC-05 | Фильтрация по отделу | Отображаются сотрудники отдела |
| TC-06 | Просмотр статистики | Статистика отображается корректно |
