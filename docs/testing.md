# Тестирование системы

| ID    | Тест                            | Ожидаемый результат                              |
| ----- | ------------------------------- | ------------------------------------------------ |
| TC-01 | Открытие страницы сотрудников   | Отображается список сотрудников                  |
| TC-02 | Поиск сотрудника по ФИО         | Найден нужный сотрудник                          |
| TC-03 | Фильтрация по подразделению     | Отображаются сотрудники выбранного подразделения |
| TC-04 | Фильтрация по кадровому статусу | Отображаются сотрудники с выбранным статусом     |
| TC-05 | Сброс фильтров                  | Отображаются все сотрудники                      |
| TC-06 | Просмотр карточки сотрудника    | Отображается информация о сотруднике             |
| TC-07 | Просмотр списка подразделений   | Отображается перечень подразделений              |
| TC-08 | Просмотр статистики             | Статистические данные отображаются корректно     |
