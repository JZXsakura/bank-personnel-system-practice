# Описание проекта

## Тема проекта

**Информационная система по учёту персонала в банке**

## Актуальность проекта

В современных организациях, особенно в банковской сфере, большое значение имеет качественный и своевременный учёт персонала. Банк может включать множество подразделений, сотрудников, должностей и кадровых статусов. При использовании бумажных документов или разрозненных таблиц возникают проблемы с поиском информации, обновлением данных, контролем статусов сотрудников и формированием отчётности.

Разработка информационной системы по учёту персонала позволяет упростить работу HR-отдела, ускорить поиск нужных сведений, снизить вероятность ошибок и обеспечить более удобное хранение кадровой информации.

## Цель проекта

Целью проекта является разработка учебного прототипа веб-ориентированной информационной системы для автоматизации учёта сотрудников банка, хранения информации о персонале, подразделениях и кадровых данных.

## Основные задачи проекта

Для достижения цели необходимо выполнить следующие задачи:

* изучить предметную область кадрового учёта в банке;
* определить основные сущности системы: сотрудники, подразделения, должности, кадровые статусы;
* разработать структуру проекта и подготовить Git-репозиторий;
* создать документацию проекта в формате Markdown;
* разработать статический сайт с описанием проекта;
* создать прототип пользовательского интерфейса информационной системы;
* реализовать страницы для просмотра сотрудников, подразделений и статистики;
* подготовить материалы для итогового отчёта по практике;
* разместить результаты работы в GitHub-репозитории.

## Назначение системы

Разрабатываемая система предназначена для автоматизации основных процессов учёта персонала в банке. Она может использоваться HR-специалистами, руководителями подразделений и администраторами для просмотра, поиска и анализа информации о сотрудниках.

## Планируемый функционал

В рамках учебного проекта планируется реализовать следующие разделы:

### Главная страница

Главная страница содержит краткое описание системы, её назначение и основные возможности.

### Сотрудники

Раздел предназначен для отображения списка сотрудников банка. Для каждого сотрудника указываются:

* табельный номер;
* ФИО;
* должность;
* подразделение;
* кадровый статус.

Также предусматривается возможность поиска и фильтрации сотрудников.

### Личная карточка сотрудника

Карточка сотрудника содержит более подробную информацию:

* ФИО;
* дата рождения;
* должность;
* дата приёма;
* стаж;
* контакты;
* подразделение;
* текущий статус.

### Подразделения

Раздел содержит список основных подразделений банка, например:

* HR-отдел;
* кредитный отдел;
* отдел рисков;
* IT-отдел;
* финансовый отдел;
* служба безопасности.

### Статистика

Раздел статистики предназначен для отображения обобщённой информации:

* общее количество сотрудников;
* количество сотрудников по подразделениям;
* распределение по должностям;
* количество сотрудников с разными кадровыми статусами.

## Используемые технологии

В проекте используются следующие технологии:

* HTML — для создания структуры веб-страниц;
* CSS — для оформления интерфейса;
* JavaScript — для реализации простых интерактивных элементов;
* Markdown — для оформления документации;
* Git — для контроля версий;
* GitHub — для хранения репозитория проекта.

## Ожидаемый результат

В результате выполнения проекта должен быть создан учебный прототип информационной системы по учёту персонала в банке, включающий статический сайт проекта, интерфейсные страницы системы, документацию в формате Markdown и итоговый отчёт по проектной практике.

Проект позволит продемонстрировать навыки работы с Git, Markdown, HTML, CSS, базового проектирования информационных систем и подготовки технической документации.
