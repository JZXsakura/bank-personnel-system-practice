# Вклад участников проекта

## Общая информация

Проект «Информационная система по учету персонала в банке» выполняется группой из трех участников.
Работа была разделена на несколько направлений: анализ предметной области, подготовка документации, разработка сайта проекта, создание пользовательского интерфейса прототипа информационной системы, оформление материалов и подготовка итоговой презентации.

Такое распределение позволило каждому участнику отвечать за отдельную часть проекта и одновременно работать над общим результатом.

---

## Объедков Сергей Александрович — документация и анализ предметной области

**ФИО:** Объедков Сергей Александрович

### Зона ответственности

Объедков Сергей Александрович отвечает за теоретическую и аналитическую часть проекта.

### Выполненные задачи

* подготовка введения к проекту;
* описание актуальности темы;
* анализ предметной области кадрового учета в банке;
* описание основных бизнес-процессов учета персонала;
* выделение ключевых сущностей информационной системы;
* анализ существующих способов решения задачи учета персонала;
* подготовка текстовых материалов для итогового отчета.

### Результат работы

В результате работы участника была подготовлена основа аналитической части проекта, включающая описание предметной области, анализ задачи учета персонала в банке и обоснование необходимости разработки информационной системы.

**ФИО:** Денисюк Тимофей Андреевич

### Зона ответственности

Денисюк Тимофей Андреевич отвечает за визуальную и пользовательскую часть проекта: сайт проекта, интерфейс прототипа информационной системы, оформление страниц, подготовку графических материалов и публикацию сайта.

### Выполненные задачи

* разработка структуры сайта проекта;
* создание главной страницы сайта;
* создание страницы «О проекте»;
* создание страницы «Участники»;
* создание страницы «Журнал»;
* создание страницы «Ресурсы»;
* разработка единого визуального стиля сайта;
* создание прототипа пользовательского интерфейса информационной системы;
* разработка главной панели прототипа;
* разработка страницы сотрудников;
* реализация поиска и фильтрации сотрудников;
* создание страницы карточки сотрудника;

* настройка переходов между страницами;
* публикация сайта через GitHub Pages;
* подготовка технического руководства по сайту и прототипу.

В результате работы участника был создан статический сайт проекта и прототип интерфейса информационной системы по учету персонала в банке.
Сайт содержит основные сведения о проекте, участниках, ходе работы и полезных ресурсах.
Прототип демонстрирует работу с сотрудниками, подразделениями, карточкой сотрудника и статистикой.

## Вывод

Командная работа позволила разделить проект на несколько логичных частей.
Каждый участник отвечал за свое направление, а итоговый результат был объединен в общем GitHub-репозитории.
Такой подход помог организовать работу, отслеживать изменения через Git и подготовить материалы для защиты проектной практики.
