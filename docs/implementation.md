# Реализация функций

## Хранение данных

В текущей версии проекта данные сотрудников хранятся в виде массива JavaScript в файле `src/app.js`. Такой подход используется для демонстрации работы интерфейса без подключения серверной части и базы данных.

## Отображение сотрудников

Список сотрудников формируется динамически средствами JavaScript на основе демонстрационного набора данных.

## Поиск сотрудников

Поиск выполняется по ФИО сотрудника. Результаты отображаются в таблице без перезагрузки страницы.

## Фильтрация данных

Реализована фильтрация сотрудников по подразделению и кадровому статусу. Пользователь может комбинировать фильтры для получения необходимой выборки данных.

## Статистика

Страница статистики отображает сведения о количестве сотрудников по подразделениям и кадровым статусам на основе демонстрационных данных.

## Пользовательский интерфейс

Интерфейс системы реализован средствами HTML, CSS и JavaScript. Навигация осуществляется через меню и ссылки между страницами проекта.

## Перспективы развития

В дальнейшем возможно подключение серверной части и базы данных PostgreSQL, MySQL или SQLite для хранения кадровой информации и реализации полноценного CRUD-функционала.
