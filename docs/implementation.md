# Реализация функций

## Хранение данных

В текущей версии проекта данные сотрудников хранятся в массиве JavaScript в файле src/app.js.

## Поиск сотрудников

Поиск выполняется средствами JavaScript по ФИО сотрудника.

## Фильтрация

Фильтрация выполняется по подразделению и кадровому статусу сотрудника.

## Статистика

Страница статистики отображает сведения о количестве сотрудников по отделам и статусам на основе демонстрационных данных.

## Перспективы развития

В дальнейшем возможно подключение серверной части и базы данных PostgreSQL, MySQL или SQLite.
