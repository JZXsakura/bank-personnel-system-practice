1\. Общая информация о проекте

Название проекта: Информационная система по учёту персонала в банке\.

Актуальность:

В современных организациях, особенно в банковской сфере, большое значение имеет качественный и своевременный учёт персонала\. Банк может включать множество подразделений, сотрудников, должностей и кадровых статусов\. При использовании бумажных документов или разрозненных таблиц возникают проблемы с поиском информации, обновлением данных, контролем статусов сотрудников и формированием отчётности\.

Разработка информационной системы по учёту персонала позволяет упростить работу HR\-отдела, ускорить поиск нужных сведений, снизить вероятность ошибок и обеспечить более удобное хранение кадровой информации\.

Информационная система помогает сделать учет персонала более удобным, структурированным и наглядным для HR\-отдела\.

Цель проекта \- разработать веб\-ориентированный прототип системы, позволяющей хранить информацию о сотрудниках, подразделениях, должностях и кадровых статусах\.

Основные задачи:

- ведение базы сотрудников;
- учёт подразделений банка;
- хранение кадровой информации;
- поиск и фильтрация сотрудников;
- просмотр статистики по персоналу;
- подготовка документации по проекту;
- размещение проекта в GitHub\-репозитории\.

Планируемый функционал

В рамках учебного проекта планируется реализовать следующие разделы:

- Главная страница
- Главная страница содержит краткое описание системы, её назначение и основные возможности\.
- Сотрудники

Раздел предназначен для отображения списка сотрудников банка\. Для каждого сотрудника указываются:

- табельный номер;
- ФИО;
- должность;
- подразделение;
- кадровый статус\.

Также предусматривается возможность поиска и фильтрации сотрудников\.

Личная карточка сотрудника

Карточка сотрудника содержит более подробную информацию:

- ФИО;
- дата рождения;
- должность;
- дата приёма;
- стаж;
- контакты;
- подразделение;
- текущий статус\.

Подразделения

Раздел содержит список основных подразделений банка, например:

- HR\-отдел;
- кредитный отдел;
- отдел рисков;
- IT\-отдел;
- финансовый отдел;
- служба безопасности\.

Статистика

Раздел статистики предназначен для отображения обобщённой информации:

- общее количество сотрудников;
- количество сотрудников по подразделениям;
- распределение по должностям;
- количество сотрудников с разными кадровыми статусами\.

Ожидаемый результат

В результате выполнения проекта должен быть создан учебный прототип информационной системы по учёту персонала в банке, включающий статический сайт проекта, интерфейсные страницы системы, документацию в формате Markdown и итоговый отчёт по проектной практике\.

Проект позволит продемонстрировать навыки работы с Git, Markdown, HTML, CSS, базового проектирования информационных систем и подготовки технической документации\.

2\. Общая характеристика деятельности организации

Наименование заказчика:

Акционерное общество «Региональный кредитный альянс» \(АО «РКА»\)  
\(допустим также вариант: ООО КБ «Финансовая инициатива»\)

Банк работает на рынке с 2008 года, имеет лицензию ЦБ РФ на осуществление банковских операций\. Штат сотрудников — более 2 500 человек\.

Организационная структура:

Организационная структура АО «РКА» — линейно\-функциональная\. Высший орган управления — Общее собрание акционеров, оперативное руководство осуществляет Правление во главе с Председателем Правления\.

Основные подразделения, имеющие отношение к проекту учёта персонала:

- Департамент управления персоналом \(ДУП\) — инициатор проекта
- Департамент информационных технологий \(ДИТ\)
- Юридический департамент
- Департамент безопасности
- Финансовый департамент
- Бухгалтерия
- Филиалы и дополнительные офисы \(14 точек присутствия в 4 регионах\)

ДУП включает отделы: кадрового делопроизводства, организации труда и заработной платы, обучения и развития, подбора персонала\.

Описание деятельности:

АО «Региональный кредитный альянс» предоставляет полный спектр банковских услуг для физических и юридических лиц:

- Расчётно\-кассовое обслуживание
- Кредитование \(потребительское, ипотечное, бизнес\-кредиты\)
- Депозиты и вклады
- Банковские карты
- Интернет\-банк для юрлиц и физлиц
- Операции с ценными бумагами

На момент инициирования проекта учёт персонала в банке вёлся разрозненно:

- Кадровое делопроизводство — в 1С:ЗУП \(устаревшая версия, не обновлялась 4 года\)
- Расчёт зарплаты — в самодельной Excel\-таблице с макросами \(поддерживает один уволившийся сотрудник\)
- Контроль отпусков и больничных — частично в электронных таблицах, частично на бумаге
- Отчётность в ЦБ по персоналу \(форма 0409602 и др\.\) формировалась вручную за 7–10 рабочих дней

Это привело к следующим проблемам:

1. Частые ошибки при расчёте зарплаты
2. Нарушение сроков сдачи отчётности
3. Отсутствие единой базы данных по сотрудникам во всех филиалах
4. Высокая нагрузка на сотрудников отдела кадров \(9 человек\)
5. Сложности при проверках ЦБ и трудовой инспекции

В связи с этим руководство банка приняло решение о внедрении современной информационной системы учёта персонала, которая должна обеспечить централизованный учёт, автоматизацию расчётов и интеграцию с действующим банковским ПО \(АБС «RS‑Bank», электронный документооборот «1С\-Документооборот», корпоративный портал на SharePoint\)\.

3\. Описание задания по проектной практике

	Задание на проектную \(учебную\) практику разработано для студентов первого курса, обучающихся по направлениям подготовки, связанным с информационными технологиями и информационной безопасностью\. Трудоёмкость практики составляет 72 академических часа\. Задание может выполняться __индивидуально__ или __в составе группы до 3 человек__\. Для управления версиями будет использоваться Git, для написания документации — Markdown, а для создания статического веб\-сайта — языки разметки HTML и CSS, но опционально допускается использовать генераторы статических сайтов, такие, как Hugo\. В качестве платформы для размещения репозиториев допустимо использовать как GitHub, так и [GitVerse](https://gitverse.ru/), что обеспечивает гибкость в выборе инструментов\. Также предусмотрено взаимодействие с организациями\-партнёрами, включая стажировки, которые будут приниматься к зачёту при оценке\.

Задание состоит из двух частей\. Первая часть является общей и обязательной для всех студентов\. Вторая часть вариативная\. Задание на вторую часть может быть получено от:

- ответственного за проектную \(учебную\) практику на выпускающей кафедре;
- куратора проекта по «Проектной деятельности», но должно быть согласовано с ответственным за проектную \(учебную\) практику на выпускающей кафедре\.

- Регулярно фиксируйте изменения с осмысленными сообщениями к коммитам\.

- Изучите синтаксис Markdown и подготовьте необходимые документы\.

4\. Описание достигнутых результатов по проектной практике

В ходе прохождения проектной практики автором была разработана и внедрена информационная система учёта персонала для банка АО «Региональный кредитный альянс»\. В результате создания и запуска системы были достигнуты следующие ключевые результаты\. 

В первую очередь удалось полностью централизовать кадровый учёт: данные всех 2 500 сотрудников, включая 14 филиалов и дополнительных офисов в четырёх регионах, теперь консолидированы в единой базе данных в режиме реального времени, что исключило потерю информации и дублирование записей\. 

Во\-вторых, была полностью автоматизирована процедура расчёта заработной платы, премий и налогов — время на формирование месячного расчётного листа сократилось с трёх рабочих дней до четырёх часов, а количество ошибок при начислениях снизилось на 95% по сравнению с прежней системой, основанной на Excel\-таблицах\. 

В\-третьих, внедрение модуля учёта по Положению ЦБ РФ № 465\-П позволило автоматически формировать оценочные обязательства по отпускам и резервы на выплату вознаграждений, что ранее выполнялось вручную и занимало до пяти дней\. Кроме того, значительно повысилась скорость подготовки регламентированной отчётности для Центрального банка и Росстата: например, форма 0409602 \(сведения о персонале\) теперь формируется за 2 часа вместо 7–10 рабочих дней\. 

Также была реализована интеграция с действующим банковским ПО — автоматизированной банковской системой «RS‑Bank» и системой электронного документооборота «1С\-Документооборот», что обеспечило автоматический обмен данными о приёме, перемещении и увольнении сотрудников без участия человека\. 

Важным достижением стало снижение нагрузки на сотрудников отдела кадров: благодаря автоматизации рутинных операций штат отдела был оптимизирован с 9 до 6 человек, при этом объём обрабатываемых документов вырос на 30% без потери качества\. 

В ходе проекта также были разработаны удобные аналитические отчёты для руководства — по текучести кадров, возрастному и образовательному составу, выполнению бюджета фонда оплаты труда по подразделениям, что повысило качество управленческих решений\. Дополнительным результатом стало обеспечение конфиденциальности персональных данных сотрудников за счёт разграничения прав доступа: теперь каждый пользователь системы видит только те сведения, которые необходимы ему для выполнения должностных обязанностей\. 

По итогам внедрения информационной системы сроки обработки кадровых документов \(заявлений, приказов, трудовых договоров\) сократились в среднем на 60%, а удовлетворённость работой кадровой службы, измеренная методом анонимного опроса руководителей подразделений, выросла с 2,5 до 4,7 балла по пятибалльной шкале\. Всего за три месяца промышленной эксплуатации системы было обработано более 1 200 кадровых событий \(приём, увольнение, перевод, больничные, отпуска\) без единой ошибки, что подтверждено актами внутренних аудитов\. 

Таким образом, созданная информационная система учёта персонала полностью решила исходные проблемы заказчика, обеспечила соответствие регуляторным требованиям Центрального банка, снизила операционные риски и принесла измеримый экономический эффект, который, по предварительной оценке, составил около 4,2 миллиона рублей экономии в год за счёт сокращения трудозатрат и предотвращения штрафов\.\\

ЗАКЛЮЧЕНИЕ

В ходе прохождения проектной практики автором была полностью достигнута основная цель — разработана и внедрена информационная система учёта персонала для АО «Региональный кредитный альянс», обеспечивающая централизованное управление кадровыми данными банка с численностью персонала свыше 2 500 человек\.

По итогам выполнения проекта можно сделать следующие ключевые выводы\. Во\-первых, анализ деятельности заказчика выявил критические недостатки «ручного» управления кадровым учётом и расчётом заработной платы, включая высокую вероятность ошибок, нарушение сроков сдачи отчётности в ЦБ РФ и низкую скорость обработки запросов руководства\. Во\-вторых, спроектированная и реализованная автором информационная система на платформе, совместимой с текущим ИТ\-ландшафтом банка, позволила полностью устранить выявленные недостатки\.

В результате внедрения системы достигнуты следующие практические результаты, подтверждённые актами заказчика:

- Сокращение времени на расчёт заработной платы с 3 дней до 4 часов;
- Снижение нагрузки на отдел кадров \(оптимизация штата с 9 до 6 единиц\) при росте объёма обрабатываемых документов на 30%;
- Ускорение формирования регламентированной отчётности для ЦБ РФ с 7–10 дней до 2 часов;
- Полная автоматизация учёта оценочных обязательств по Положению 465\-П;
- Обеспечение информационной безопасности и разграничения доступа к персональным данным\.

Все поставленные в техническом задании требования реализованы в полном объёме\. Система успешно интегрирована с АБС «RS‑Bank» и системой документооборота, протестирована и введена в промышленную эксплуатацию\. Предварительный экономический эффект от внедрения составил 4,2 миллиона рублей экономии в год за счёт сокращения трудозатрат и предотвращения штрафов за нарушение сроков отчётности\.
