# Информационная система по учету персонала в банке

## Описание проекта

Проект выполнен в рамках проектной практики и посвящен разработке учебного прототипа информационной системы для автоматизации учета персонала в банке.

Система предназначена для хранения информации о сотрудниках, подразделениях, должностях и кадровых статусах. Проект демонстрирует основные возможности веб-интерфейса для HR-отдела банка: просмотр сотрудников, поиск, фильтрацию, карточку сотрудника и статистику по персоналу.

## Цель проекта

Разработать сайт и прототип веб-ориентированной информационной системы, позволяющей упростить учет сотрудников банка и сделать работу с кадровыми данными более удобной и наглядной.

## Основные задачи

* изучить предметную область кадрового учета в банке;
* определить основные сущности системы;
* разработать структуру проекта;
* создать статический сайт проекта;
* реализовать прототип интерфейса информационной системы;
* добавить страницы сотрудников, подразделений, карточки сотрудника и статистики;
* реализовать поиск и фильтрацию сотрудников;
* подготовить документацию в формате Markdown;
* разместить проект в GitHub-репозитории;
* опубликовать сайт с помощью GitHub Pages.

## Как открыть проект локально

1. Склонировать репозиторий:

```bash

```

2. Перейти в папку проекта:

```bash
cd bank-personnel-system-practice
```

3. Открыть сайт проекта:

```text

```

4. Открыть прототип информационной системы:

