# Информационная система по учёту персонала в банке

## Описание проекта

Проект посвящён разработке информационной системы для автоматизации учёта персонала в банке.  
Система предназначена для хранения информации о сотрудниках, подразделениях, должностях, кадровых статусах и формирования простой статистики для HR-отдела.

## Цель проекта

Разработать учебный прототип веб-ориентированной информационной системы, позволяющей упростить работу с кадровыми данными сотрудников банка.

## Основные задачи

- ведение базы сотрудников;
- учёт подразделений банка;
- хранение кадровой информации;
- поиск и фильтрация сотрудников;
- просмотр статистики по персоналу;
- подготовка документации по проекту;
- размещение проекта в GitHub-репозитории.
