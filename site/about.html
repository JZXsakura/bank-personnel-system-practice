Описание проекта

О проекте

Проект посвящён разработке учебного прототипа информационной системы для автоматизации учета персонала в банке.

Актуальность

В банковской сфере важно быстро и точно работать с кадровыми данными. При использовании таблиц или бумажных документов возникают проблемы: сложно искать сотрудников, обновлять данные, контролировать статусы и формировать отчеты.

Информационная система помогает сделать учет персонала более удобным, структурированным и наглядным для HR-отдела.

Цель проекта

Цель проекта - разработать веб-ориентированный прототип системы, позволяющей хранить информацию о сотрудниках, подразделениях, должностях и кадровых статусах.

Основные задачи

📁

Хранение данных

Создание структуры для хранения информации о сотрудниках, должностях, отделах и кадровых статусах.

🔎

Поиск и фильтрация

Подготовка интерфейса для быстрого поиска сотрудников по ФИО, отделу, должности и статусу.

📈

Статистика

Отображение общей информации о количестве сотрудников, распределении по отделам и кадровым статусам.

Ожидаемый результат

В результате выполнения проекта будет создан статический сайт проекта, прототип пользовательского интерфейса информационной системы, документация в формате Markdown и итоговый отчет по проектной практике.

Проект демонстрирует навыки работы с Git, HTML, CSS, JavaScript, Markdown, проектированием интерфейсов и подготовкой технической документации.
